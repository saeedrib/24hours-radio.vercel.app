# 24HOURS RADIO

A responsive online radio station website concept for 24HOURS RADIO.

## Deploy on Vercel
1. Import this repository into Vercel.
2. Framework preset: Other.
3. Build command: leave empty.
4. Output directory: `.`
5. Deploy.

## Live audio
The player is ready, but the station needs a real audio streaming endpoint (Icecast/SHOUTcast or a managed radio streaming provider). Add the public stream URL to `STREAM_URL` in `index.html`.

A stream URL is not supplied by this repository. Do not use copyrighted music without the required rights.

## Current stage
This is the public website foundation. Supabase authentication, secure admin/DJ roles, shared program management, podcast storage, listener analytics and FM studio integration are not connected yet. The on-page station setup is only a local preview and is not a secure admin panel.
